# 3D Multiplayer Room

Онлайн-мультиплеер в 3D-комнате: несколько игроков одновременно заходят с телефонов и компьютеров, видят друг друга и перемещаются в реальном времени через интернет.

Всё работает через **один Node.js-сервер**, который раздаёт HTML-клиент, обслуживает WebSocket и хранит комнаты в памяти. Разворачивается как **один Web Service на Render**.

## Стек

- **Клиент:** HTML5 + CSS3 + JavaScript + Babylon.js (CDN)
- **Сервер:** Node.js + Express + ws
- **Хостинг:** Render (бесплатный план подходит)
- **Репозиторий:** GitHub

## Возможности

- Реальные онлайн-комнаты с кодом доступа
- До 10 игроков в комнате
- Синхронизация позиции, поворота, ходьбы и бега
- 3D-персонажи из Babylon.js-примитивов с уникальными цветами
- Полноценный интерьер: стены, пол, потолок, дверь, окна, диван, стол, стулья, шкаф, растения
- Коллизии со стенами и мебелью
- Камера от третьего лица
- Управление WASD + мышь (ПК), виртуальный джойстик + свайп (телефон)
- Валидация всех сообщений на сервере
- Автоматическое переподключение при потере связи

## Требования

- Node.js **18+** — https://nodejs.org
- Аккаунт GitHub
- Аккаунт Render — https://render.com

## 1. Локальный запуск

### 1.1. Создать папку проекта

```bash
mkdir multiplayer-game
cd multiplayer-game
```

### 1.2. Создать файлы

Создайте ровно четыре файла:

- `server.js`
- `package.json`
- `README.md`
- `.gitignore`

Вставьте содержимое из соответствующих блоков.

### 1.3. Установить зависимости

```bash
npm install
```

### 1.4. Запустить сервер

```bash
npm start
```

Вы увидите:

```
Server listening on port 3000
```

### 1.5. Открыть игру в браузере

Откройте http://localhost:3000

### 1.6. Проверить двух игроков локально

1. Откройте http://localhost:3000 в одном окне браузера
2. Введите имя, нажмите **«Создать комнату»**
3. Скопируйте 6-значный код
4. Откройте http://localhost:3000 в другом окне (или в режиме инкогнито)
5. Введите другое имя, вставьте код, нажмите **«Войти по коду»**

Оба персонажа появятся в одной комнате и будут видеть перемещения друг друга.

## 3. Развёртывание на Render

### 3.1. Создать Web Service

1. Зайдите на https://dashboard.render.com
2. Нажмите **New → Web Service**
3. Подключите GitHub-аккаунт
4. Выберите ваш репозиторий `multiplayer-game`

### 3.2. Настройки сервиса

- **Name:** любое, например `multiplayer-game`
- **Region:** ближайший к вам
- **Branch:** `main`
- **Runtime:** `Node`
- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **Instance Type:** `Free` (если доступен)

Нажмите **Create Web Service**.

### 3.3. Открыть публичный адрес

После первого деплоя (1–3 минуты) Render выдаст адрес вида:

```
https://multiplayer-game-xxxx.onrender.com
```

Откройте его в браузере — игра уже работает.

Клиент автоматически определит `wss://` из HTTPS-контекста. **Менять адрес вручную не нужно.**

## 4. Проверка с двух телефонов

1. Отправьте другу ссылку Render
2. На своём телефоне откройте ссылку → введите имя → **«Создать комнату»**
3. Скопируйте 6-значный код и отправьте другу
4. Друг открывает ту же ссылку, вводит имя и код → **«Войти по коду»**
5. Оба появляетесь в одной 3D-комнате и видите перемещения друг друга

Управление:
- **Телефон:** левый джойстик — движение, правый свайп — камера, кнопка «Бег» — ускорение
- **ПК:** `WASD` — движение, мышь — камера, `Shift` — бег, `Esc` — выход из режима захвата курсора

## 5. Ограничения бесплатного Render

- Сервис **засыпает** после ~15 минут неактивности. Первый запрос после сна занимает 30–60 секунд — просто обновите страницу.
- **Комнаты хранятся в памяти.** При перезапуске сервиса все комнаты исчезают — это нормально для первой версии.
- Ограничения по CPU/RAM, но для этой игры их хватает с запасом.

## 6. Формат сообщений WebSocket

Клиент → сервер:

| Тип | Поля |
|---|---|
| `createRoom` | `name` |
| `joinRoom` | `name`, `code` |
| `playerMoved` | `x`, `y`, `z`, `ry`, `moving`, `running` |
| `ping` | — |

Сервер → клиент:

| Тип | Поля |
|---|---|
| `roomState` | `roomCode`, `selfId`, `players[]` |
| `playerJoined` | `id`, `name`, `color`, `x`, `y`, `z`, `ry` |
| `playerMoved` | `id`, `x`, `y`, `z`, `ry`, `moving`, `running` |
| `playerLeft` | `id` |
| `error` | `message` |
| `pong` | `t` |

Сервер является источником истины: координаты ограничиваются границами комнаты, скорость перемещения — максимально допустимой, размер сообщений — 2 КБ, частота — до 80 сообщений/сек на клиента.
